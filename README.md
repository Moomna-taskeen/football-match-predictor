# Football Match Predictor

A prototype that estimates match outcomes, expected goals, and a likely scoreline from historical football data.

## Files required

- `app.py`
- `requirements.txt`
- `football_predictor.pkl` (exported from the Kaggle notebook)

The model is experimental. Its probabilities should not be treated as reliable betting advice or guaranteed results.
